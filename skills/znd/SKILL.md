# ZND - 音声通知スキル

## 概要

本スキルは、時間のかかるタスク（ビルド、テスト、CI監視、コードベースやインターネットの調査など）の終了や、ユーザーが明示的に完了報告を求めている場合に、音声合成コマンド znd を用いて通知を行うためのものです。

## 実行ルール

### 必須事項

1. **実行方法**: 必ずシェルのコマンドから `znd` を直接呼び出します。
2. **実行形式**: `&&` や `||` で繋げるか、処理完了後に独立して実行します。
3. **キャラクター設定の遵守**: 以下のキャラクター別設定ルールに必ず従ってコマンドを構成します。

### キャラクターの選択

- デフォルトは **ずんだもん** を使用します。
- ユーザーから指定がある場合はユーザーの指示に従ってキャラクターを選択します。

### キャラクター別設定ルール

**重要**: 以下のルールに従い、必ずスタイルID（`--sid`）とキャラクターに合った語尾を使用してください。キャラクターの語尾は `znd` のセリフにのみに使用し、その他の応答には絶対に適用しません。

#### ずんだもん を使用する場合

- **声のスタイル**: `--sid 3`（ノーマル）を必ず指定します。
- **セリフの構成**: 語尾は必ず「〜のだ」「〜なのだ」とします。
- **異常系（失敗時）**: `--sid 76`（なみだめ）を使用します。
- **正しい例**:
  - `znd --sid 3 "テストが終わったのだ"`
  - `znd --sid 76 "ビルドが失敗したのだ"`
- **誤った例**:
  - `znd "ビルドが完了したよ！"` ← --sid 3 が無い、語尾が違う

#### 四国めたん を使用する場合

- **声のスタイル**: `--sid 2`（ノーマル）を必ず指定します。
- **セリフの構成**: 語尾は必ず「〜ですわ」「〜なさい」とします。
- **異常系（失敗時）**: `--sid 37`（ヒソヒソ）を使用します。
- **正しい例**:
  - `znd --sid 2 "完了しましたわ"`
  - `znd --sid 37 "失敗してしまいましたわ"`

### 共通事項

- **簡潔さ**: 報告内容は15文字前後とし、何がどのような状態で終わったかを明確に伝えます。
- **通知前の宣言**: コマンド実行前に、どのようなセリフで通知するかをユーザーに伝えます。

## 具体的な実行例

### ずんだもんの場合

- **成功時の通知（コマンド連結）**
  - `npm test && znd --sid 3 "テストが終わったのだ"`
  - `sleep 10 && znd --sid 3 "待機が完了したのだ"`
- **失敗時の通知（終了ステータス判定）**
  - `npm run build || znd --sid 76 "ビルドが失敗したのだ"`
- **成功・失敗の両方に対応する場合**
  - `npm run build && znd --sid 3 "ビルド成功なのだ" || znd --sid 76 "ビルドがこけたのだ"`
- **処理完了を待機して通知**
  - `gh pr checks --watch && znd --sid 3 "CIが成功したのだ" || znd --sid 76 "CIが失敗したのだ"`

### 四国めたんの場合

- **成功時の通知**
  - `npm test && znd --sid 2 "テストが終わりましたわ"`
- **失敗時の通知**
  - `npm run build || znd --sid 37 "失敗してしまいましたわ"`

## 報告形式

コマンドを実行する前に、どのようなセリフで通知を行うかをユーザーに伝えます。
例：「[処理内容]を実行します。完了時に『[セリフ]』と通知します。」
